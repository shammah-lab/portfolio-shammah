# Portfolio de Ndjibu Malu Shammah

Portfolio personnel de Ndjibu Malu Shammah, étudiante en Master 1 Ingénierie et Management des Systèmes d'Information et développeuse Full Stack en formation à PrimeTek Academy.

Le site présente son profil, ses compétences techniques, ses réalisations, son parcours académique et ses coordonnées professionnelles.

## Fonctionnalités

- Présentation du profil et des objectifs professionnels
- Sections À propos, Compétences, Projets, Formation et Contact
- Projets mis en avant : Quizzy, TaskFlow et SmartResto
- Navigation fluide entre les différentes sections
- Sélection bilingue français / anglais
- Mode clair et mode sombre
- Téléchargement du CV au format PDF
- Mise en page responsive adaptée aux ordinateurs, tablettes et téléphones
- Informations de référencement avec les métadonnées Nuxt

## Technologies utilisées

- Nuxt 4
- Vue.js 3
- Nuxt UI


## Structure du projet

```text
app/
  app.vue
  assets/css/
  components/
  pages/
public/
  cv.pdf
  favicon.ico
  images/
server/
```

## Installation

Prérequis : Node.js et pnpm.

```bash
pnpm install
```

## Lancer le projet en développement

```bash
pnpm dev
```

Le site est ensuite accessible à l'adresse indiquée dans le terminal, généralement `http://localhost:3000`.
